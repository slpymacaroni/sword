# Sword
This is a repository for my little platformer made in GDscript :)
It was originally based off of the GOAT Brackey's tutorial: https://www.youtube.com/watch?v=LOhfqjmasi0

You could probably tell based off of the fact that I am still using some of the assets from the tutorial lol

If you want to try it out, here is a link to an (outdated) version from a few weeks ago: https://sleepymacaroni.itch.io/local-slime-infestation (placeholder name)
I am aware that the web version is quite laggy, but whatever lol idk anymore. 

Oh yeah and name is still TBD

This project was originally created almost a year and a half ago as of writing this (11/17/2026) as my very first godot game. It was then submitted to the very serious juniper dev game jam, and I am still working on it to this day. As such, this is the result of months of tweaks, changes, new features, but here is the main stuff I did to differentiate it from just being a tutorial project:

-Added simple combat, with a three-hit VERY BUGGY combo system and jump attacks

-Made my own tileset and sprites

-Made my own level design

-Added wall jumps, coyote time, variable jump height, a dash ability and other tweaks

-Added enemy AI with a state machine

-Made a HP system

-Made a HUD (sort of)

-Added particles and a parallax BG

-And more...

What I'm working on right now:

-Isometric world map to switch between levels

-A new enemy that I like to call a seedling (name TBD) which is just a slime but tankier and that'll charge at you or something similar

-A parry function cuz that's always fun

-An actual working inventory system with weapons and consumables

-Making more levels obviously

And of course, every game developer's canon event... Adding more juice like the ADHD 5 year old that I sometimes am
